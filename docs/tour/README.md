# APRSERJi application tour

Every tab, panel, tool and Setup section, on the Mac, iPad, iPhone and Apple Watch. The stations and messages are made-up demo data around Goose Lake Prairie State Natural Area, Grundy County, Illinois. `./tour.sh` makes these screenshots again.
